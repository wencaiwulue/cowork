# Composer @ Mentions and / Slash Commands

## Overview

The desktop composer supports two trigger characters:
- `@` for mentioning agents, teams, files, skills, and MCP servers
- `/` for slash commands (prompt templates, navigation, creation, settings)

## Architecture

### Detection Layer (`composerMenu.ts`)
- `composerTrigger(input, cursor)` — detects `@` or `/` after whitespace/start using regex `/(?:^|\s)([@/])([^\s@/]*)$/`
- `applyComposerMenuValue(insertion)` — replaces the trigger region with selected value + trailing space
- Trigger is computed live at cursor position AND end of input

### Live Parsing Layer (`App.tsx`)
- `parsedMentions` useMemo — scans entire input with regex `/@(skill:[\w-]+|mcp:[\w-]+|[^\s@]+)/g`
- Categorizes each match by checking against available: agents → teams → files → skills/mcp
- Returns `ParsedMention[]` with kind, value, label, raw text, and index

### Target Resolution
- `resolveChatTargetFromInput(text)` uses parsed mentions to determine:
  1. **Chat target** — first @agent or @team found (priority: agent wins)
  2. **Clean text** — all @mentions stripped out
  3. **Context mentions** — @file, @skill, @mcp references (annotated in prompt)
- On send: agent targets launch subagent tasks, team targets broadcast to team, session targets send normally

### Live UI Sync
- useEffect watches parsedMentions and updates chatTarget state automatically
- When user types @agent, the "Send to" dropdown updates in real-time
- Colored mention chips appear below the target selector showing detected mentions
- Routing indicator (→ Agent: name / → Team: name) shows where message will go

## Slash Commands

### Groups
1. **Prompt**: `/review-diff`, `/explain-file`, `/run-tests`, `/fix-bugs`, `/refactor` — generate pre-written prompts
2. **Navigation**: `/terminal`, `/files`, `/refresh` — switch panes or refresh workspace
3. **Create**: `/new-agent`, `/new-team`, `/new-global-task`, `/add-mcp`, `/new-skill` — open creation forms
4. **Settings**: `/plugins`, `/reload-config`, `/diagnostics` — settings actions

### Behavior
- **Navigation/Create/Settings** — execute immediately via `.action()` callback
- **Prompt commands** — insert prompt text and auto-send via setTimeout(sendMessage, 50ms)
- Prompt text is generated by `slashPrompt(command)` function

## File References
- @file mentions are stripped from outgoing text
- Context annotation `[Referenced file: path]` is prepended to the message
- Files are matched against the workspace tree by exact path or suffix

## Skill/MCP References
- @skill:name and @mcp:name mentions are stripped from outgoing text
- Context annotations `[Using skill: name]` / `[Using MCP server: name]` are prepended
- These serve as hints to Claude about which skills/tools to use

## Styling
- `.mention-chip` — pill badge with icon, color-coded by type
- `.mention-agent` (green), `.mention-team` (blue), `.mention-file` (yellow), `.mention-skill` (purple), `.mention-mcp` (pink)
- `.mention-routing` — text showing routing destination
